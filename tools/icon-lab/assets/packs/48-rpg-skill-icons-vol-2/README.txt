48 RPG SKILL ICONS - VOL 2

48 active-ability icons for a hotbar, spellbook or skill tree - true pixel
art, real pixel grid, no anti-aliasing, 32x32 and 64x64. This is the
sequel to the original RPG Skill Icons pack, built from scratch with a
much bigger, better-organized set: melee attacks, spells, and support
abilities instead of a small mixed bag.

WHAT'S IN THE BOX

png_32/         48 icons, true pixel art style, 32 x 32
png_64/         the same at 64 x 64
png_32_x4/      32x32 upscaled 4x (nearest-neighbor, still crisp pixels)
png_32_x8/      32x32 upscaled 8x
png_64_x4/      64x64 upscaled 4x
png_64_x8/      64x64 upscaled 8x
aseprite/32/    .aseprite source files at 32 x 32
aseprite/64/    .aseprite source files at 64 x 64
atlas/          sprite sheet + coordinates
palette/        shared colour palette swatch
preview/        promo sheets

Every file is a square transparent PNG with the background fully cut.
