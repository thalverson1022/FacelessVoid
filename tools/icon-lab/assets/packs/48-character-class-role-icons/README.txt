48 CHARACTER CLASS & ROLE ICONS

48 character class/role emblem icons, in two styles: a true pixel art
version (real pixel grid, no anti-aliasing, 32x32 and 64x64) and a bonus
smooth flat-vector version at 512/256/128px for anyone who wants a
cleaner look at larger sizes. Built for a character-select screen, a
class picker, a party roster, or any RPG that needs a big set of
distinct class emblems.

WHAT'S IN THE BOX

png_512/        48 icons, smooth flat-vector style, 512 x 512
png_256/        the same at 256 x 256
png_128/        the same at 128 x 128
png_32/         48 icons, true pixel art style, 32 x 32 (plus _x4/_x8 upscales)
png_64/         the same at 64 x 64 (plus _x4/_x8 upscales)
aseprite/32/    .aseprite source files at 32 x 32
aseprite/64/    .aseprite source files at 64 x 64
atlas/          sprite sheet + coordinates
palette/        shared colour palette swatch
preview/        promo sheets

Every file is a square transparent PNG with the background fully cut.
