- `talent:talent.quick_hands`: Assassin / Quick Hands; Bladedancer / Weakness
- `talent:talent.precision`: Assassin / Precision; Bladedancer / Whetstone
- `talent:talent.bypass`: Assassin / Bypass; Bladedancer / Opportunity
- `talent:talent.critical_poison`: Assassin / Critical Poison; Bladedancer / Virulent Corruption
- `skill:draft.skill.venom_jab`: Assassin / Venom Jab; Bladedancer / Quick Cut
